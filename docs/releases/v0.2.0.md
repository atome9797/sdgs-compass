학생은 수상·제출·참가 실적을 **자랑 글**로, 기업은 SDGs 활동을 **홍보 글(PR 표시)** 로 올리는 **SNS 피드**를 웹·Android 앱·DB 설계에 더했어요. 웹 데모는 QR 로 바로 열 수 있어요.

## 바뀐 것
- 피드(웹·앱): 전체 / 기업 홍보 / 학생 자랑, 좋아요(내 글 제외) · 내 글 삭제 · 증명서·챌린지 보기 · 공유
- 글쓰기: 자랑 글(내 실적 1건 선택, 본문 200자) · 홍보 글(제목 40자, 본문 400자, SDGs 1~3개, 챌린지 연결)
- 공식 SNS(Instagram 스토리) 게시 신청: 하루에 한 회사, 내일부터 빈 날짜를 자동 배정 (게시료 ¥3,000 은 샘플 값이고, 실제로 게시되지는 않고 신청 기록만 남아요)
- 이메일·전화번호처럼 보이는 글자는 올릴 수 없음
- 학생·기업 모두 하단 탭 6개(피드는 둘째)
- DB: 표 62개 · 뷰 6개, 앱과 DB 규칙 대조 시험 포함 6개 파일
- README: 흐름도·시연 순서·화면 표·목업 갱신
